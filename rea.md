## 📞 Support

### If Something Doesn't Work
1. Check QUICK_START.md
2. Clear browser cache (Ctrl+Shift+Delete)
3. Refresh page (Ctrl+F5)
4. Try different browser
5. Check browser console for errors (F12)

### Common Issues

**Portfolio won't save:**
- Check validation errors (red text)
- Name is required
- Make sure browser allows localStorage

**Data disappeared:**
- Click "Save Portfolio" to save
- Don't just refresh without saving
- Download PDF as backup

**Image not showing:**
- Use direct image URL (.jpg, .png)
- Check URL is valid
- Try different image

**PDF not downloading:**
- Use Ctrl+P for print dialog
- Select "Save as PDF"
- Choose location and save
